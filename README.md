Entry for the make.fun bounty **news-image-20261122** ("Sum up 22 November's world news in one image").

- `entry.png`: the 1024×1024 broadsheet image, drawn by `build.py` (Pillow, build time only).
- `main.py`: Python 3.13, standard library only. It copies `entry.png` to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`).
